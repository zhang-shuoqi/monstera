# Monstera 全书 · 分镜稿（全界面 / 全状态 / 全文案规格书）

> 版本：v1.0 ｜ 效力：与《总纲》同级。总纲管施工纪律，本书管建成内容。
> 施工规则：本书中的每个数字、每句文案都是终稿。AI 施工 = 查表抄写，禁止自行设计。
> 本书中"〔验收〕"标记处，是验收 AI 的测试点。

---

## 第 0 章 · 使用说明

三份文档的分工：
- **信条**（一段话）：为什么做——回答"这个决定对不对"
- **总纲**：怎么管——回答"AI 怎么施工不出乱子"
- **本书**（本文件）：做什么——回答"每个像素、每句话长什么样"

你的日常：AI 给出方案 → 对照信条；AI 开始施工 → 对照总纲章程；AI 说做完了 → 拿本书逐条验收。

## 第 1 章 · 设计基准（数值宪法，全书所有数字的出处）

### 1.1 颜色
| 用途 | 值 | 说明 |
|---|---|---|
| 正文/最高权 | #E9E8EF | 纯白微暖 |
| 强调/焦点 | #E3C79F | 金，仅用于：焦点、active、live 指示 |
| 次级 | rgba(233,232,239,.45) | 说明、元数据 |
| 弱 | rgba(233,232,239,.34) | 费用、边角 |
| hairline | rgba(233,232,239,.07~.16) | 分组边界，7% 为轮次盒、16% 为强调边 |
| 背景面差 | rgba(233,232,239,.025~.06) | 档案盒底、hover、live 高亮 |
| 面板底 | #0A191E | 页面底色，全局唯一深色 |
| 成功 | 边 rgba(107,203,119,.26) 底 .055 | 只表达状态 |
| 失败 | 边 rgba(231,111,81,.3) 底 .06 | 只表达状态 |
| 用户头像底 | rgba(99,179,237,.12) 字 #7fb8e6 | 全界面唯一的蓝，只属于用户 |

### 1.2 字阶（px / 字重）
27 衬线欢迎标题 → 21 600 引导标题 → 14.5 正文（用户消息/模型正文）→ 13.5 次正文 → 12.5 600（chip 标题/终态卡标题/面板标题）→ 12（面板大标题）→ 11.5（live 条/按钮）→ 11（证据行/弱正文）→ 10.5（计量/元数据/mono 详情）→ 9.5（徽章/标签，letter-spacing .06~.18em）
正文行高 1.75，消息 1.7，证据行 1.5。

### 1.3 留白四档
页边 42px → 消息组间 26px → 组内 22px → 组件内 16px → 微间距 6~10px → 2~3px。
规则：横向留白 > 纵向消息间距 > 组件内 > 微间距。留白是主要分组工具，边框只是暗示。

### 1.4 圆角
档案盒/终态卡 10px → chip 7px → 证据行 6px → 消息 14px(单边 4px) → 胶囊 999px。

### 1.5 动效白名单（全书仅这些允许动，参数终稿）
| 名称 | 参数 | 触发 | 禁止 |
|---|---|---|---|
| msgIn | .24s ease-out 淡上移 | 消息入场瞬间 | 循环 |
| nmIn/ovIn/popIn | .2~.26s ease | 卡片/覆盖层/菜单入场 | 循环 |
| tdotBounce | 1s infinite | 仅流式首个字符到达前 | 正文开始即移除 |
| blink | 1s step-start | 流式光标 ▌，随流式结束移除 | 常驻 |
| hover/focus | .12s | 交互反馈 | — |
除此以外的一切循环动画（pulse/pulseLine/pulseDot/spinner）全部废除。执行中指示 = 稳定金色小点 + 一档背景差，不跳。〔验收：任务静置 30 秒，屏幕无任何循环动画〕

## 第 2 章 · 全局时间线（任务一生的九幕）

这是全书的"时间轴"，每个界面元素只在下面的幕里登场：

**幕一 · 空白** → **幕二 · 立目标** → **幕三 · 计划确认（可选）** → **幕四 · 执行中** → **幕五 · 轮次结算（执行中循环发生）** → **幕六 · 终态** → **幕七 · 审问** → **幕八 · 追溯历史** → **幕九 · 中断恢复**

任意时刻任意幕，界面上只允许出现该幕规定的元素。出现别的 = 穿帮。

## 第 3 章 · 区域 A 分镜（侧栏）

### A1 新对话按钮
- 位置：侧栏顶部。文案：「+ 新对话」
- 常态：11.5px，次级色；hover：一档背景差 + 金字
- 〔验收〕点击后输入框聚焦，侧栏无其他变化

### A2 模式切换（agent / ask）
- 两个等宽分段，胶囊容器，10.5px 标签间距 .06em
- active 段：金字 + 金色 16% hairline 边 + 6% 金底；inactive：34% 灰
- 选择持久化（monstera.mode）
- 〔验收〕切换时聊天区与面板立即整体换装，无中间混合态

### A3 侧栏入口
- 图标按钮，34% 灰；hover 60%；折叠后窗口收窄至 0，状态持久化

### A4 历史区（对话 + 任务两个折叠组）
- 组头：9.5px 大写字距 .18em，42% 灰，右侧 chevron
- 条目：12.5px，单行截断（P2），hover 一档背景差；active：左侧 2.5px 金条 + 渐变
- 空态文案：对话「暂无对话」/ 任务「暂无任务」，34% 灰，居中
- 条目右键菜单：重命名 / 删除 / 导出（预留坑 R6 接通后启用）
- 组折叠状态**持久化**（现状缺口，第二卷修复）
- 〔验收〕切换历史条目后返回，滚动位置与各组折叠状态保持

## 第 4 章 · 区域 B 分镜（聊天内容框 · 叙事层）

> 白名单五种：B1 用户目标 / B2 模型正文 / B3 过程摘要 chip / B4 终态卡 / B5 live 条。
> 铁律复述：任何原始 JSON、参数、堆栈、内部名出现在此区域 = 事故。

### B1 用户目标
- 右对齐，蓝色小头像（30px 圆）在最右，气泡在左于头像
- 14.5px / 1.7，底 4.5% 白、边 14% 白，圆角 14px 单边 4px，padding 10×15
- 发送中：气泡透明度降至 .6（状态陈述，不用 spinner）
- 发送失败：气泡下方一行 11px 红字「发送失败」+ 「重试」按钮
- 〔验收〕全文可读，无截断（用户的话永远完整展示）

### B2 模型正文
- 左对齐无气泡无卡片，14.5px / 1.75，max-width 80%
- 标题：21px 600 金→白渐变（仅 Agent 引导）；正文内 h2 15px 600
- 列表/步骤：12~13px；长回复超 8 行折叠为前 8 行 + 「展开全文」，展开后此会话内保持
- 流式：正文逐字出现，光标 ▌随动，到达即移除
- 代码块：mono 12px，深色底，右上角复制钮（hover 显现），左上语言标签 9.5px
- 〔验收〕流式期间用户上翻阅读不被拉回（P4 主权）

### B3 过程摘要 chip
- 一行：chevron(9px) + 人话摘要 12.5px 62% 灰 + 右侧状态点
- 折叠态默认；展开显示 mono 10.5px 详情区（P1 保活：展开活过任意 SSE 帧）
- **人话映射表（终稿，施工抄写用）**：
  | 内部名 | 显示文案 |
  |---|---|
  | file_read | 读取文件 |
  | file_write | 写入文件 |
  | file_edit | 修改文件 |
  | list_dir | 查看目录 |
  | run_command / shell | 执行命令 |
  | search / grep | 搜索内容 |
  |（其余工具） | 动词+宾语结构，禁止驼峰/下划线原名 |
- 摘要句式：「动词 + 对象 + 结果」，例：「读取 config.py 等 3 个文件 · 成功」
- 〔验收〕grep 聊天区渲染代码，无任何工具内部名拼接进 DOM

### B4 终态卡（全界面唯一实体卡）
- 结构：左侧 19px 实心圆图标 → 标题 12.5px 600 → 元信息行 10.5px 40% 灰 → 可选「查看详情」
- 四种终态文案终稿：
  1. **成功**：标题「任务完成」；元信息「耗时 2m14s · 12 步 · 8 次工具 · ¥0.031」；图标绿实圆 ✓
  2. **失败**：标题「任务失败」；正文一行 = 事实+出路，例：「迭代达到上限（50 轮）· 可缩小目标范围后重试」；「查看详情」展开原文入折叠；图标红实圆 ✕
  3. **中断**：标题「任务已被中断」；正文「应用重启或连接断开所致，证据已封存，可从第 N 轮重试」+「重试」按钮；图标灰实圆 ⏸
  4. **计划被拒**：标题「计划未执行」；正文「计划未获确认，任务已安全停止，未做任何修改」；图标灰实圆
- padding 11×13，圆角 10，hairline 按 1.1 节状态色
- 终态卡出现时**无动画庆祝**，入场仅 msgIn
- 〔验收〕四种终态逐一手动触发，文案逐字比对本书

### B5 live 条（sticky 航标）
- 仅幕四出现；sticky top 6px；胶囊：金字 11.5px + 左侧 7px **稳定**金点
- 文案：「正在执行 · 第 N 轮 · 一句话当前动作」例：「正在执行 · 第 4 轮 · 修改路由配置」
- 动作句来自翻译表，每轮结算更新一次；SSE 断线时文案变为「连接中断，正在重连」34% 灰
- 点击 live 条 = 定位到执行面板当前轮（接口 I2 反向）
- 〔验收〕滚出视口再滚回，live 条始终可见；静置无脉冲

## 第 5 章 · 区域 C 分镜（执行面板 · 卷宗室）

### C1 计量条（台账）
- 面板顶部固定不滚；10.5px 42% 灰；五项：步数 / 工具调用 / 耗时 / tokens / 费用
- 格式终稿：「12 步 · 8 工具 · 2m14s · 48.2k tok · ¥0.031」；空值显示「—」绝不显示 undefined/NaN
- 底部 6% hairline 与流区分隔；**数字只随事件结算更新，不做跳动动画**
- 〔验收〕执行中盯着计量条，数字跳变但无动画补间

### C2 轮次卷宗（档案盒）
- 每轮一个盒子：底 rgba(233,232,239,.025) + 边 7% hairline + 圆角 8px + margin-bottom 3px
- 头部一行：chevron + 「第N轮」11px 600 #c6c3cc + 人话摘要（截 60 字）+ 右侧徽章 9.5px：
  - 待执行 灰 / **执行中 金（稳定）** / 完成 绿 / 失败 红
- 默认折叠；点击头部展开（P1，状态持久化）
- 展开内容 = 证据行列表（见 C3）；整个面板区域走 P4 滚动主权
- 历史轮次默认折叠，当前轮默认展开——"默认折叠历史、展开是用户动作"的唯一例外
- 〔验收〕10 轮任务：第 1 轮与第 10 轮视觉规格完全一致（一致性 = 档案馆的秩序感）

### C3 证据块（每轮的证物袋）
- 三种证据行，图标 + 11px 人话 + 右侧状态点（成功绿/失败红）：
  1. **文件证据**：「修改 src/app.py」+ 展开 diff：mono 10.5px，+行绿底 / −行红底，52vh 限高，默认折叠超 20 行
  2. **命令证据**：「执行 npm install」+ 展开命令原文（$ 开头 mono 灰）与输出（mono 灰，超 2000 字截断带标记）
  3. **结论证据**：「观察：测试全部通过」纯文本行
- 证据行 hover 一档背景差；详情区底 rgba(0,0,0,.32)
- 原始载荷**只许存在于此区域**，且永远默认折叠
- 〔验收〕任一证据展开 → 等 10 个 SSE 帧 → 展开态仍在

### C4 静默航标
- 当前轮高亮 = 头部 5% 金底 + 标题金色，**无发光无脉冲无左边条动画**
- 当前证据行左侧 3px 纯色金条（静态）
- 轮次头点击 → 聊天流定位到该轮首条消息（接口 I2）；消息的过程 chip 点击 → 面板定位该轮（I1）
- 定位动作 = 目标元素滚动入视口居中 + 一档背景差闪烁一次后恢复（唯一允许的"引导性"动效，.3s）
- 〔验收〕3 秒锚点测试：10+ 轮任务滚走后回来，3 秒内指认出当前轮

### C5 终止区（footer）
- 成功/失败：状态陈述一行 11px 34% 灰，失败时附「重试」按钮
- 中断：「任务已被中断」+「从第 N 轮重试」
- 〔验收〕任务停止后 footer 无 spinner、无空转、无残留文案

## 第 6 章 · 预留坑分镜（R1-R6 内容全文，将来施工照抄）

### R1 计划视图（区域 C 计量条之下）
- 意图行：「目标是：一句话复述用户目标」12.5px
- 步骤列表：状态点（待/进行中/完成/跳过）+ 人话步骤 + 可展开理由；全部默认折叠
- 与 B3 的区别：B3 说"做了什么"，R1 说"打算做什么"

### R2 记忆面板（区域 A 历史区内折叠组）
- 条目：时间 10.5px 灰 + 摘要一行 + 来源标签（会话/任务）9.5px
- 交互：查看（展开全文）/ 删除；**无编辑入口**——证据先封存，操作后留痕
- 空态：「暂无记忆」

### R3 技能/工具配置（设置齿轮展开区）
- 纯表单：开关 + 参数输入；保存后 toast「已保存」
- 铁律：此区域禁止出现任何运行态信息

### R4 多模型对比（区域 B 终态卡之下的专用容器）
- 结论行：「两个模型的结论一致/分歧在 X」先行
- 每个模型一列：名称 + 终态卡同规格小卡；细节默认折叠
- 铁律：对比不打扰单模型任务的原生流程

### R5 本地证据检索（区域 C 顶部检索条）
- 输入框 + 结果列表：命中上下文两行 mono + 「定位到轮次」按钮
- 检索范围：证据块全文 + 事件摘要；这就是"审问"的正门

### R6 归档/导出（区域 A 条目右键）
- 导出格式：md（叙事）/ json（全量事件）/ zip（含证据文件）
- 铁律：导出 = 通用格式，离开 Monstera 也能读（本地主权的延伸）
