## A.1 版本与获取（钉死，不漂移）

- 版本：**alpinejs@3.17.1**（2026-04 发布，经核验维护健康：31.8k star、周下载 45 万+）
- 获取：下载 `https://cdn.jsdelivr.net/npm/alpinejs@3.17.1/dist/cdn.min.js` → 存入 `vendor/alpine.min.js`
- 加载：`<script defer src="/vendor/alpine.min.js"></script>`，必须 `defer`，且顺序在所有业务 `js/ch*` 之前
- 禁止：运行时引用任何 CDN；禁止 `@3.x.x` 浮动版本

## A.2 三条硬规则（违反 = 返工）

### 规则一：组件作用域纪律（防大列表崩塌）
Alpine 社区共识：非大型数据密集型框架，整组件重评估是其模型；但 `:key` 能保证未变元素的内部状态保留（出处：官方讨论 #570、v3.15.9 x-for 性能优化 #4361）。
- 每个轮次卷宗（TurnBox）= 独立 `x-data` 作用域（P6 内部自管折叠态）
- 全局 store（ch10）只存：会话列表、当前任务元信息、轮次**索引**（序号列表）
- 轮次数据追加即弃：新轮 push 进索引，旧轮数据不回改、不重排
- `:key` 一律用轮次序号，禁止省略、禁止用数组 index 以外的临时值
- 禁止在 TurnBox 内嵌套第二个 `x-for` 渲染证据行——证据行用 TurnBox 作用域内的局部状态渲染

### 规则二：流式正文绕开响应式（防"每帧重建"复活）
- 流式期间（幕四）：直接 `textContent` 追加，不碰 Alpine 状态
- 流结束（幕六）：一次性提交最终文本到 store，Alpine 接管渲染
- blink 光标/tdot 等流式指示由 ch15 命令式控制，不进 x-data

### 规则三：实现细则（官方文档约束，照抄）
- 页面根元素加 `x-cloak` + CSS `[x-cloak]{display:none}`，防初始化前闪屏
- `x-for` 只能写在 `<template>` 上，且 template 内只能有一个根元素
- `x-if` 不支持过渡动画——终态卡、live 条等需要 msgIn 入场的元素用 `x-show` + CSS 类
- store 注册必须在 DOMContentLoaded 前完成（`Alpine.store(...)` 放 ch10 顶部）

## A.3 第一卷补充验收

在总纲第一卷验收基础上追加：
1. 断网启动：拔掉网络，页面功能完整（验证 vendor 本地加载）
2. 250 轮任务：滚动、展开、定位无卡顿；任一轮展开态稳定存在
3. 流式期间 CPU 占用与改造前持平或更低（性能回退 = 违反规则二）
4. 控制台零 Alpine 警告（x-cloak/key 缺失警告 = 不合格）
