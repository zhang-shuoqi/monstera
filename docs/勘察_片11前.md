## A. 布局结构

### 1. 三栏用 grid 还是 flex？宽度定义在哪、现值多少？

**flex**（非 grid）。

- 总容器 `.app{display:flex;height:100vh;position:relative;overflow:hidden}` — `css/_style.css:36`
- 左栏 `.sidebar{flex:0 0 var(--side-w,20%); min-width:150px; max-width:38%}` — `css/_style.css:39-41`
  - 默认现值 = 百分比填充 `--side-w` 未设时 20%；1280 窗口下约 256px（但被 `min-width:150px` / `max-width:38%` 夹住）
- 左/中分割条 `.resizer{flex:0 0 5px}` — `css/_style.css:173`
- 中栏 `.chat{flex:1;min-width:0}` — `css/_style.css:186`（自适应，无固定 px）
- 右栏 `.agent-pane{flex:0 0 var(--agent-w,26%); min-width:0}` — `css/_style.css:232-234`
  - 默认现值 = `--agent-w` 未设时 26%；1280 窗口下约 333px
- 拖拽调宽（运行期覆盖）：`attachResizer($('resizerSide'),'--side-w',…)` 与 `attachResizer($('resizerAgent'),'--agent-w',…)`，写 `appEl.style.setProperty` 为 px — `js/ch16-legacy.js:3296-3297`
  - 侧栏限幅 `Math.max(150, Math.min(innerWidth*0.4, x))`；右栏限幅 `Math.max(220, Math.min(innerWidth*0.5, innerWidth - x))`
- 宿主窗口默认 1280×820，min 960×640 — `desktop/main.js:161-164`

### 2. 侧栏、右栏折叠机制现状

**侧栏（默认展开）**
- 折叠类名：`.app.side-hidden`；效果 `display:none`（重排，聊天区占满）— `css/_style.css:167-168`
- 触发：`#wcSideBar` click toggle `side-hidden` — `js/ch16-legacy.js:3262-3265`
- 持久化键：`localStorage 'monstera.sideHidden'`（唯一侧栏键）— 写 `ch16:3264`，读 `ch16:3268`
- 其它持久化键（与折叠无关）：`'monstera.mode'`（`ch16:2126/2132/3257`）、`'monstera_always_allow'`（`ch16:2619/2623`）

**右栏（Agent 面板，默认折叠）**
- 折叠类名：`.agent-pane` 基础 `display:none` — `css/_style.css:232-238`
- 展开态：`.agent-pane.open → display:flex` — `css/_style.css:239`；仅 `.app.mode-agent` 下可显（`L238`）
- 触发：`setAgentPane(open)` 切换 `.open` ＋ `#resizerAgent.hidden` ＋ `#wcRight.wcs-open` — `js/ch16-legacy.js:3300-3308`
- 持久化键：**无**（纯内存态，刷新即回到折叠）
- 折叠行为同为 `display:none` 重排（非覆盖层/非 fixed 覆盖）

### 3. 空白态时右栏默认展开还是折叠？

### 5. 输入框定位方式
**静态流内**（flex column 底部），非 fixed/absolute。
- `.chat{display:flex;flex-direction:column}` — `css/_style.css:186`
- `.messages{flex:1}` 占满顶部，`.composer-wrap` 自然落底 — `css/_style.css:665-671, 751`
- 随内容的位置逻辑 = 纯 CSS 空态类切换：`.chat--empty .composer-wrap{flex:1; justify-content:center}`（有内容回落底部）— `css/_style.css:221-224`
- 空态类由 `syncAgentComposer()` 依据「有内容/无内容」toggle `chat--empty` — `js/ch16-legacy.js:2187-2192`

### 6. 项目内媒体查询 / 布局模式
- `@media` 全项目仅两处，**均非响应式宽度断点**：
  - `@media (hover:none)`（触屏操作条常显）— `css/_style.css:513`
  - `@media (prefers-reduced-motion:reduce)` — `css/_style.css:1706`
- 无任何 `@media (max-width/min-width:…)`，**无响应式断点**
- 无独立 data-mode 布局断点；存在的是「模式 + 折叠」类，控制列显隐：
  - `data-mode="chat"/"agent"`（HTML 模式钮）— `index.html:49-50`
  - `.app.mode-agent` 切换中间叙事列/右栏显隐 — `css/_style.css:279, 289, 238-239`
  - `.app.side-hidden`、`.app:not(.side-hidden)` — `css/_style.css:167, 1831`

### 截图取证限制（必须如实申报）
- 本环境嵌入式浏览器**内视口固定 984×617，无法程序化缩放到 1280／1200**（`window.resizeTo` 被忽略；`window.open(…,width=…)` 弹窗不被追踪，无法截图）。
- 故三张图实际均截于 **984×617** 桌面内视口；**未能截到字面 1200px 宽度**。
- 依据 A.6（flex 布局、无任何 `@media` 断点），窗口在 1280→1200→…→984 区间内**布局结构不重排、无隐藏列断点**，仅各列按现宽度比整体变窄；right 列保持可见与否只看 `.open`（非宽度）。
- E7 规范若指代「固定 viewport + 禁动画 + 同浏览器同缩放」基线拍照法，本三图满足「同视口、同缩放、同浏览器取三态」；但真实物理窗口缩放的 1200px 证据本次缺失。
