# Monstera 黄金场景清单（第零卷 · 行为基线）

> 本文件是每一片迁移的行为对比标尺。改动前把「当前预期行为」钉死，
> 每迁一片后重跑相关场景录屏与基线对比：旧行为该保留的分毫不动，新行为符合《全书》分镜。
> 录屏：每段 ≤2 分钟，普通手机录屏即可。由主人执行录屏，AI 只维护本清单。

## 十条场景

| # | 场景 | 操作 | 当前预期行为 |
|---|---|---|---|
| S1 | 打开应用空白态 | 冷启动进入首页 | 空白输入框垂直居中，无模型时显示引导卡 |
| S2 | 发起一次对话（ask 模式） | 聊天模式输入并发送 | 用户气泡靠右，AI 流式逐字输出 |
| S3 | 流式回答中上翻再回底 | 回答流式进行时上滚阅读，再点「回到底部」 | 上翻时自动跟随暂停、不被拉回；点按钮回底恢复跟随 |
| S4 | 发起 Agent 任务 | Agent 模式输入目标并执行 | 右侧执行面板展开，中间出现用户目标 + live 条 |
| S5 | 执行中展开一个过程 chip | 执行中点击某个过程摘要 chip | chip 展开显示详情，关键字样与配色正确 |
| S6 | 执行中上翻被拉回（现状 bug） | 执行中向上滚动中间时间线 | 被强拉回底部（此行为是 bug，新建行为应修复为不拉回） |
| S7 | 任务成功终态 | 任务执行到完成 | 终态卡「任务完成」，无循环动画，无空转 loading |
| S8 | 手动停止 | 执行中点击停止 | 任务标注中断，证据保留，无残留 loading |
| S9 | 刷新页面恢复任务 | 任务执行中刷新页面 | 后端把中断任务标记 failed，前端从事件流完整重建 |
| S10 | 切换历史会话 | 侧栏点击任一历史会话 | 消息完整加载，滚动位置与折叠状态保持 |

## 验收规则

- 每迁移一片，重跑「相关场景」录屏，与基线对比。
- 需要保持的旧行为：S1/S2/S3/S4/S5/S7/S8/S9/S10 各自既定行为，分毫不动。
- 需要改变的新行为：S6（执行中上翻不得被拉回）——片 1 的验收点。
